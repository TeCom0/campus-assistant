# Campus AI Assistant

A multilingual (English/French) AI assistant for Al Akhawayn University students. It answers questions
about academic policies, the course catalog, and scholarships, citing its sources, and uses an agent to
query structured data (e.g. "what are the prerequisites for ACC 2302?").

Status: Phase 4 in progress (LangGraph agent). See `CLAUDE.md` for the full project plan and working
conventions.
